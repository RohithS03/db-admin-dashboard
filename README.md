## 📌 Overview

**DB Admin Dashboard** is a web-based database administration console providing real-time database health metrics, active connection tracking, query execution profiling, schema inspection, and automated backup operations.

---

## ✨ Key Features

- 🔍 **Live Query Inspector & Profiler:** Track slow queries and index usage.
- ⚡ **Connection Pool Analytics:** Monitor active, idle, and max connections.
- 🗄️ **Schema Visualizer:** Table structure, foreign key relationships, and row counts.

---

## 🚀 Quick Start Guide

```bash
git clone https://github.com/RohithS03/db-admin-dashboard.git
cd db-admin-dashboard

pip install -r requirements.txt
python app.py
```
